# أذكاري تُنير يومي — النسخة القابلة للتثبيت

## تفعيل النسخة الجديدة في المستودع الحالي

1. فك ضغط الملف ZIP.
2. افتح https://github.com/AminaQatan/Adhkari-Muslim-Kid ثم Add file → Upload files.
3. ارفع جميع الملفات المستخرجة إلى الصفحة الرئيسية للمستودع، ومنها `index.html` و`book.html` والصور وملفا `manifest.webmanifest` و`sw.js`. وافق على استبدال `index.html` القديم، ثم Commit changes.
4. لا ترفع ZIP نفسه ولا تضع الملفات داخل مجلد إضافي.
5. بعد نجاح نشر GitHub Pages، افتح https://aminaqatan.github.io/Adhkari-Muslim-Kid/ في Chrome وحدّث الصفحة؛ يجب أن يظهر زر «حفظ التطبيق» في الأعلى.

لم تُنشر هذه الحزمة آليًا: الاتصال بـGitHub رفض الكتابة إلى المستودع. هذه الملفات جاهزة للرفع اليدوي، ولا حاجة إلى إعادة إنشاء المستودع أو تغيير رابط الموقع.

## الاستخدام على الهاتف

1. افتح رابط GitHub Pages في Chrome على Android، أو Samsung Internet على هاتف Samsung.
2. اضغط «حفظ التطبيق» ثم أكد التثبيت. إذا لم يظهر مربع التثبيت، افتح قائمة المتصفح واختر «إضافة إلى الشاشة الرئيسية» ثم «تثبيت».
3. تظهر أيقونة «أذكاري» على الشاشة الرئيسية. عند فتحها، يعمل الكتيّب في نافذة مستقلة.
4. اترك التحميل الأول يكتمل حتى تظهر عبارة «محفوظ • جاهز دون إنترنت». بعدها يعمل الكتاب والصوت دون اتصال، ما دامت بيانات الموقع محفوظة على الجهاز.
5. اضغط «ابدأ القراءة والاستماع» مرة واحدة لتفعيل الصوت، ثم تتبع القراءة التنقل بين صفحات الأذكار.

في iPhone: افتح الرابط في Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية.
فتح ملف HTML من التنزيلات لا يدعم التثبيت؛ يلزم رابط HTTPS منشور.

## الملفات

- `index.html`: واجهة تثبيت التطبيق وعرض الكتاب.
- `book.html`: الكتيّب الأصلي كاملًا، مع الصور والخطوط والصوت المضمّن. يمكن فتحه مباشرة للقراءة من جهاز الكمبيوتر.
- `manifest.webmanifest`: اسم التطبيق وأيقونته ونطاقه وإعداد النافذة المستقلة.
- `sw.js`: حفظ ملفات هذا التطبيق للعمل دون إنترنت. النطاق مستقل عن تطبيقات GitHub Pages الأخرى في الحساب.
- `icon.svg` وملفات PNG: الأيقونة القابلة للتعديل ومقاساتها للهواتف.
- `.nojekyll`: نشر الملفات كما هي عبر GitHub Pages.

## إعادة النشر والتعديل

ارفع جميع الملفات في المجلد الأساسي للمستودع، مع الحفاظ على اسم `index.html`.
فعّل Settings → Pages → Deploy from a branch → main → /(root).
لا توجد عملية بناء أو قاعدة بيانات أو مفاتيح API أو خدمات صوت خارجية وقت التشغيل.
للتجربة محليًا: شغّل `python3 -m http.server 8000` من مجلد الملفات، ثم افتح `http://localhost:8000`.
عند تحديث الملفات، غيّر رقم الإصدار في ثابت `CACHE` داخل `sw.js` حتى يعاد حفظ النسخة الجديدة.
لا تحذف `book.html`؛ فهو يحتوي الكتاب والصور والتسجيلات.

## الصوت والمحتوى

الكتاب ٣٢ صفحة. الصوت متوفر في ٢٦ صفحة من صفحات الأذكار؛ دعاء حسن الخلق عند المرآة ما زال بلا تسجيل بشري مطابق. لم يُستبدل التسجيل المفقود بصوت آلي.
أذكار حصن المسلم بصوت حمد الدريهم، وتلاوات السور بصوت أحمد سعود. بعض التسجيلات تتضمن تتمة الذكر أو صيغتي الصباح والمساء.
المصادر الصوتية الأصلية: https://www.hisnmuslim.com/ و https://mp3quran.net/ . التسجيلات محفوظة داخل الكتاب ولا تُجلب من هذه المواقع أثناء التشغيل.

النسخة تطبيق ويب قابل للتثبيت وليست ملف APK أو تطبيقًا منشورًا في Google Play أو App Store.
